# Code of Conduct

Be respectful, constructive, and welcoming to learners of all backgrounds. Critique ideas and code, not people. Harassment, discrimination, personal attacks, and publishing another person's private information are not tolerated.

Maintainers may edit or remove harmful content and restrict participation. Report concerns privately through the repository's GitHub security advisories or contact the repository owner through their GitHub profile. Do not post sensitive reports publicly. We will review reports and respond as capacity allows.
